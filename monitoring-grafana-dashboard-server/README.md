# Monitoring Grafana Dashboard Server

Không bắt buộc file cấu hình ban đầu — datasource Prometheus và dashboard
được tạo trong UI Grafana.

- Truy cập: http://localhost:3000 (admin / admin)
- Datasource: Prometheus → `http://monitoring-prometheus-server:9090`
- Dashboard gợi ý: "Node Exporter Full"
